=== 0.1.1 (awesome fork, tag v0.1.1-awesome.1) / 2026-10-25

* Replace the bit-struct dependency with BMP::PackedStruct.

  * bit-struct 0.15.0 is under the Ruby License; it is no longer required.
  * lib/bmp/packed_struct.rb (MIT, same license as this gem) implements the
    part of the BitStruct DSL that BMP::Obj uses (unsigned 8/16/32, char,
    rest, note, little-endian) with Array#pack / String#unpack.
  * Output is byte-identical: test/test_byte_identical.rb checks
    BMP.png_to_bmp output against sha256s recorded from upstream 0.1.1 on
    bit-struct 0.15.0, and test/test_bit_struct_parity.rb compares
    BMP::Obj with a BitStruct twin field by field (opt-in, BIT_STRUCT_LIB).
  * chunky_png relaxed from = 1.3.8 to >= 1.3.8, < 2 (1.4.0 runs on Ruby 3
    without the sorted_set gem; output unchanged).
  * Gem version stays 0.1.1 so ico 0.1.2 (= 0.1.1) still resolves.
